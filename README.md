# Welsh Technologies GitHub Organization

This repository contains the public GitHub organization profile and shared GitHub configuration for Welsh Technologies.

The organization profile is maintained in profile/README.md.

## About Welsh Technologies

Welsh Technologies is a software architecture and product engineering company with experience spanning .NET, SQL Server, cloud-connected systems, embedded Linux, and connected devices.

Today, a major focus of Welsh Technologies is the engineering behind **Musica Pristina**, a high-end digital audio company building network streamers, music servers, and long-lived digital audio systems.
